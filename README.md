# Wuthering Waves Queue

ระบบจัดการคิวรับลง Endgame ผ่านเว็บไซต์และ Google Sheets

## จุดประสงค์ของระบบ
ระบบนี้พัฒนาขึ้นเพื่อช่วยจัดการลำดับคิวรับลง Endgame ให้ผู้ใช้งานสามารถลงคิวผ่านเว็บไซต์ได้สะดวก และช่วยให้ผู้ดูแลตรวจสอบหรือเปลี่ยนสถานะคิวผ่าน Google Sheets ได้อย่างเป็นระบบ

## ความสามารถของระบบ
- ผู้ใช้งานกรอกชื่อ เลือกโหมด Endgame ระบุ Discord และหมายเหตุ
- ระบบสร้างหมายเลขคิวอัตโนมัติ เช่น Q-001
- แสดงรายการคิวและสถานะ ได้แก่ คิว, จอง, เล่นแล้ว และปิด
- ผู้ดูแลเปลี่ยนสถานะคิวผ่าน Google Sheets
- เชื่อมต่อหน้าเว็บไซต์กับ Google Apps Script

## เทคโนโลยีที่ใช้
- HTML
- CSS
- JavaScript
- Google Apps Script
- Google Sheets

## โครงสร้างไฟล์

```text
wuthering-waves-queue/
├── Code.gs        # โค้ดฝั่ง Google Apps Script
├── Index.html     # หน้าเว็บไซต์หลัก
└── README.md      # รายละเอียดโครงงาน
```

## วิธีการทำงานโดยสรุป
1. ผู้ใช้งานเปิดเว็บไซต์และกดปุ่มลงคิว
2. กรอกชื่อ เลือกโหมด Endgame ระบุ Discord และหมายเหตุ
3. ระบบบันทึกข้อมูลลง Google Sheets ผ่าน Google Apps Script
4. ระบบสร้าง Queue ID และแสดงรายการคิวบนเว็บไซต์
5. ผู้ดูแลตรวจสอบและเปลี่ยนสถานะคิวผ่าน Google Sheets
